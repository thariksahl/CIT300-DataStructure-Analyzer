# Data Structure and Graph Performance Analyzer

## 1. Project Description

The **Data Structure and Graph Performance Analyzer** is a Java-based console application developed to demonstrate the implementation and practical use of fundamental data structures, searching algorithms, and graph traversal techniques.

The application provides an interactive menu that allows users to perform operations on arrays, stacks, queues, and linked lists. It also supports graph creation using an adjacency list and graph traversal using Breadth-First Search (BFS) and Depth-First Search (DFS).

Furthermore, the system implements Linear Search and Binary Search to demonstrate how different searching algorithms locate values. A performance comparison module measures the number of search steps and execution time to help users understand algorithm efficiency.

The project emphasizes object-oriented programming, modular code organization, input validation, algorithm analysis, and collaborative software development using Git and GitHub.

### Project Objectives

* Implement and demonstrate fundamental data structures using Java.
* Perform insertion, deletion, searching, and display operations.
* Implement Linear Search and Binary Search.
* Create and manage an undirected graph using an adjacency list.
* Demonstrate BFS and DFS graph traversal algorithms.
* Compare searching algorithms using operation counts and execution time.
* Apply object-oriented programming and input validation.
* Practice teamwork, version control, branching, commits, and code integration.

### Technologies Used

* **Programming Language:** Java
* **Development Environment:** Visual Studio Code
* **Version Control:** Git
* **Source Code Management:** GitHub
* **Application Type:** Console-based application

## 3. Main Features

### Array Management

* Insert integer values.
* Delete a value.
* Search for a value.
* Display array contents.

### Stack Management

* Push values onto the stack.
* Pop values from the stack.
* View the top element.
* Display stack contents.

### Queue Management

* Enqueue values.
* Dequeue values.
* View the front element.
* Display queue contents.

### Linked List Management

* Insert nodes.
* Delete a node by value.
* Search for a value.
* Display the linked list.

### Searching Algorithms

* Linear Search.
* Binary Search on sorted data.
* Display search results and operation counts.

### Graph Management

* Add vertices and edges.
* Display the adjacency list.
* Traverse the graph using BFS.
* Traverse the graph using DFS.

### Performance Analysis and Results

* Compare Linear Search and Binary Search.
* Record the number of search steps.
* Measure execution time in nanoseconds.
* Store and display operation results.

## 4. How to Run the Project

Ensure that the Java Development Kit (JDK) is installed.

From the project root directory, run:

```bash
mkdir -p out
javac -d out src/*.java
java -cp out Main
```

The application will display the main menu. Select an option and follow the on-screen instructions.
